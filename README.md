# StockFlow Backend

Backend REST API for the StockFlow inventory management application.

## Technologies

- Java 21
- Spring Boot 4.1.1
- Maven
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- Bean Validation
- Lombok

## Project

StockFlow is an inventory management application for small and medium-sized businesses.

Main features will include:

- Product management
- Category management
- Supplier management
- Stock entries and exits
- Stock movement history
- Low-stock alerts
- Authentication and authorization
- Dashboard
